# 1.5.0 验证范围

2026-11-07：前端构建和 Rust 工作区检查通过，34 项核心测试、14 项界面测试通过。便携 CLI 的生成样本扫描、迁移、恢复和统计检查通过。

独立 Windows 11 测试电脑以普通用户权限完成 6 项 DeepSeek Harness 专项检查：

1. 生成 `DSH_HOME` 的 JSONL/Zstandard 会话扫描、历史代合计、未来格式降级和项目关联。
2. 固定 sessions/cache 适配器发现，运行中的模拟 Node 进程阻止切换。
3. 跨 NTFS 卷迁移、目录联接、SHA-256 校验、保留副本去重和实际卷统计。
4. 原路径写入新会话后，恢复时保留新增数据和原文件哈希。
5. 缓存迁移后，原路径新写入及恢复。
6. 最终源目录恢复为普通目录，无未完成迁移。

既有版本还验证了中断恢复、磁盘满、文件占用、权限拒绝、未知链接、真实 Codex 已支持目录，以及动态 VHDX 的创建、挂载任务、后续写入和恢复。

界面测试使用明确的模拟数据或合成接口回复，不能替代原生文件操作验收。DeepSeek 专项使用官方格式结构生成的样本，没有启动完整 Harness 或调用模型；不据此承诺所有插件、自定义根目录或未来格式兼容。VHDX 登录任务执行经过测试，未专项验证冷启动时序或取消 UAC 的界面流程。详见 [DeepSeek 适配范围](DEEPSEEK-HARNESS.md) 和 [虚拟磁盘边界](STORAGE-VHDX.md)。

私有测试机信息和原始验收日志不随源码发布。重新验证时应使用自己的独立测试环境。
