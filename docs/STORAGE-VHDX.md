# Move Your Agent 1.4：设置与虚拟磁盘

设置入口位于左下角、帮助上方。延续内置字体、深灰底色和紧凑表单。顶部改为同色自定义标题栏，使用 Tauri 窗口接口控制最小化、最大化、还原、关闭及拖动。

## 使用

1. 设置中选择“虚拟磁盘 VHDX + 目录联接”。镜像放在 D 盘等非系统卷，选择空闲固定盘符。保存。
2. “创建并挂载”并确认 Windows 管理员提示。默认动态镜像上限 64 GB；不会预占满额空间。
3. 启用登录时挂载。进入迁移页，默认目标是已验证的挂载卷 AgentData 目录。
4. 退出 Agent，预览具体适配器目录并确认迁移。校验后保留原副本，另行验证清理。
5. 后续 Agent 使用原路径，NTFS 目录联接将写入送到 VHDX。应用可以退出。

只覆盖迁移页已支持的目录，不更改全局 TEMP、不注入 Agent 进程，也不保证所有第三方缓存都迁移。恢复使用目标上的最新数据。

## 实现

SQLite 保存默认目录、存储方案、镜像路径、容量、盘符、磁盘 ID 和登录任务状态。Rust 核心负责设置验证、任务互斥、迁移引用检查；桌面和 CLI 共用。浏览器演示禁用实际磁盘操作，测试区模式从核心拒绝磁盘操作。

管理员 PowerShell 助手嵌入 Rust，压缩为 GZip，数据通过独立 Base64 JSON 传入。请求提权的是此受限磁盘操作，普通扫描与目录迁移保持普通用户权限。提权必须使用同一 Windows 用户，助手用 SID 核对身份，不读取或保存密码。

使用 Windows CreateVirtualDisk API 创建动态 VHDX，支持 Unicode 路径，不要求 Hyper-V 模块。仅通过指定镜像的 Get-DiskImage → Get-Disk 选择磁盘；拒绝系统/启动盘。仅在新建 RAW 镜像的受记录创建阶段初始化 GPT、创建分区、格式化 NTFS。已有镜像需匹配所有权记录、磁盘身份、分区 GUID、卷 GUID；未知镜像或被占用盘符拒绝。无镜像删除功能。

新建镜像及数据目录为当前用户、SYSTEM、Administrators 设置权限。迁移仍按来源 DACL 复制和校验，不跳过 ACL 失败。已有内容、锁、磁盘满等错误保留阶段记录和源数据。

登录任务以当前用户交互登录触发、最高权限执行，仅执行挂载分支；动作内嵌，不依赖便携程序路径。任务名含磁盘 UUID，修改任务前核对归属说明。磁盘存在未恢复的迁移或计划引用时，禁止卸载和关闭登录任务。

## 边界

- 登录挂载不能保证早于其他自启动 Agent。使用 Agent 前须确认挂载完成；这版不接管 Agent 启动顺序。
- 状态分别显示虚拟卷空闲、镜像文件大小和镜像所在卷空闲。迁移前同时检查虚拟卷与镜像所在卷空间；未来写入仍可能耗尽任一卷。
- 镜像在 C 盘不释放 C 盘实际空间；动态镜像不会随删除自动缩小。本版不提供镜像移动、扩容、压缩、多镜像管理或自动启动 Agent。
- 创建、复制、切换、恢复的中断按已记录阶段处理；身份不明或损坏的镜像保留现场并拒绝格式化。并非所有创建中断都能自动重试。
- 请一起保留便携目录的 `.lab/agent-space`、VHDX 和旁边的 `.move-your-agent.json`。丢失数据库后不自动猜测旧迁移归属。
- 自定义标题栏使用 Tauri 标准拖动区域，保留窗口调整大小和双击最大化；自绘最大化按钮不提供 Windows 原生按钮悬浮的 Snap Layout 面板。
