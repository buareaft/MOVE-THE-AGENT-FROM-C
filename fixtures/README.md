# Fixture adapter format v1

All fixtures are generated by `Lab::seed` under `.lab/agent-space/source`. No real Agent data is used or discovered. The adapter names identify example consumers only.

```text
agents/{codex|claude}/sessions/{id}.jsonl
agents/{codex|claude}/attachments/{id}/*
agents/{codex|claude}/cache/*
agents/{codex|claude}/shared/*
projects/{atlas|orbit|notes}/*
unclassified/*
```

The first session line is a JSON object:

```json
{"type":"agent_space_demo_session","schemaVersion":1,"id":"c1","title":"修复 Atlas 登录状态","project":"atlas","updated":"2026-11-06 10:30"}
```

Only matching `type`, `schemaVersion`, and filename ID establish transcript ownership. Attachments require a recognized matching session in the same Agent. Workspace association does not establish who generated any workspace file. Shared databases are opaque fixture bytes, not real SQLite databases and are never queried as Agent storage. The application's own index is a real SQLite database.
